# Parking Appeal Letter (UK private parking charges)

A free, single-page letter builder for first-stage appeals against private Parking Charge Notices in the UK.

**Not legal advice.** The page fills in a template from your answers. It does not assess your case, and no outcome is guaranteed.

**Not for council tickets.** A Penalty Charge Notice from a council, Transport for London or the police follows different rules and a different appeal route.

## What it does

- Three steps: your notice, your ground, finish. The letter updates as you type.
- Five grounds: grace or consideration period, notice to keeper arrived late, minor keying error, unclear signs, payment machine or app failure.
- Adjusts the wording for England and Wales, Scotland or Northern Ireland, and for keeper or driver.
- Copy the text, download a `.txt`, or print / save as PDF (only the letter prints).
- One file, no dependencies, no network requests. Nothing you type is sent or stored.

## Use it

Open `index.html` in a browser. To host it, serve this folder as a static site (GitHub Pages works: Settings → Pages → deploy from branch `main`, folder `/`).

## Sources

Clause numbers refer to the private parking sector single Code of Practice, version 1.1, and Schedule 4 of the Protection of Freedoms Act 2012. Last checked 11 October 2026. They need re-checking when the Code is revised or when the government's statutory code comes into force.

The wording has not been reviewed by a solicitor.
